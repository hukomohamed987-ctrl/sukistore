# 🛒 سوقي ستور (Suki Store)
### منصة تجارة إلكترونية عربية متكاملة واحترافية (RTL) بروح أمازون ونون

---

## 🌟 نظرة عامة
**سوقي ستور (Suki Store)** هو سوق إلكتروني عربي عام كامل وشامل مبني من الصفر، مصمم وفق أعلى معايير تجربة المستخدم (UI/UX) والتجارة الإلكترونية الحديثة، مع دعم أصيل وتام للغة العربية واتجاه اليمين إلى اليسار (RTL).

يجمع المشروع بين:
1. **واجهة العملاء (Storefront)**: سريعة، جذابة، متجاوبة بالكامل مع الهواتف الذكية وأجهزة الكمبيوتر، تشمل البحث المباشر مع الاقتراحات الفورية، سلة المشتريات الدائمة، إتمام الطلب، تتبع الشحنات، تقييمات المنتجات، وزر واتساب عائم.
2. **لوحة التحكم المركزية (Admin & Staff Dashboard)**: مفصولة تماماً عن العملاء، تدعم الصلاحيات المخصصة (RBAC)، تقارير ومؤشرات أداء، رسوم بيانية SVG تفاعلية، إدارة شاملة للمنتجات والخيارات الديناميكية ووحدات البيع، الطلبات، العملاء، الموظفين، الكوبونات، البانرات، ورسائل الدعم الفني.

## 🚀 التشغيل السريع (Quick Start)

### 1. المتطلبات الأساسية
- **Node.js** (إصدار 18 أو أحدث، متوافق مع Node.js 24 LTS)
- **npm**

### 2. التثبيت والتشغيل
المشروع جاهز ومثبت بالكامل داخل المجلد:
```bash
cd suki-store
npm start
```

### 3. روابط الوصول
- 🌐 **رابط المتجر للعملاء**: [http://localhost:3000](http://localhost:3000)
- 🛡️ **لوحة تحكم الإدارة**: [http://localhost:3000/#/admin](http://localhost:3000/#/admin)

## 🔑 الحسابات

كلمات مرور الحسابات الحالية **غير مكتوبة هنا عمداً** (كلمات المرور التجريبية القديمة تم تغييرها).

| نوع الحساب | البريد الإلكتروني | الصلاحيات |
|---|---|---|
| **المدير العام (Super Admin)** | `admin@suki.store` | وصول كامل لكل ميزات النظام |
| **شريك الإدارة (Super Admin)** | `ahmed@suki.store` | وصول كامل لكل ميزات النظام |
| **المحاسب (Accountant)** | `accountant@suki.store` | قسم المحاسبة وتقارير المبيعات |
| **عميل تجريبي (Customer)** | `customer@suki.store` | تصفح، سلة، شراء، وتتبع الطلبات |

> ⚠️ صلاحية المدير العام تُحدد من **نوع الحساب (role)** فقط، وليس من الاسم أو البريد.

## 📋 الميزات المنفذة بالتفصيل

### 🛍️ أولاً: واجهة العملاء (Storefront)
1. **التصميم العام**:
   - تصميم عصري بألوان زمردية ملكية (#059669) ولمسات ذهبية (#f59e0b) مستوحاة من نون وأمازون.
   - خط **Cairo** العربي المتناسق والمريح للقراءة.
   - متجاوب 100% مع الهواتف الذكية مع شريط تنقل سفلي شبيه بتطبيقات الموبايل.
   - زر واتساب عائم تفاعلي مع تأثير نبض ورسالة جاهزة في كل الصفحات.
2. **الصفحة الرئيسية**:
   - سلايدر بانرات متحرك تفاعلي مع نقاط تنقل وأسهم وعروض خاصة.
   - شريط ضمانات التسوق (شحن سريع، دفع عند الاستلام، إرجاع مجاني، دعم 24/7).
   - عرض شبكي أنيق لأقسام المتجر مع صور وعداد المنتجات.
   - قسم المنتجات المميزة (Featured) وقسم أحدث المنتجات (Latest Arrivals).
   - بانر إعلاني ترويجي لأكواد الخصم.
3. **صفحات الأقسام والتصنيفات**:
   - فلترة ذكية حسب السعر والمنتجات المخفضة فقط.
   - ترتيب المنتجات (الأحدث، السعر من الأقل للأعلى، السعر من الأعلى للأقل، الأكثر تقييماً، أعلى خصم).
4. **صفحة المنتج وتفاصيله**:
   - معرض صور متعددة مع صور مصغرة وتكبير.
   - مشغل فيديو توضيحي للمنتج في نافذة منبثقة (Modal).
   - اسم المنتج، السعر الأصلي والمخفض، وحساب نسبة التوفير فوري.
   - **وحدة البيع**: (قطعة / كيلو / لتر / علبة / كرتونة / طقم / متر...).
   - **الخيارات الديناميكية (Dynamic Variations)**: الحجم، اللون، السعة، المقاس يختار منها العميل ديناميكياً.
   - عداد الكمية (+ / -).
   - زر "أضف إلى السلة" وزر "شراء الآن" السريع.
   - التقييمات والتعليقات مع نموذج لإضافة تقييم بالنجوم وشارة "شراء مؤكد".
   - قسم المنتجات المشابهة والمقترحة.
5. **البحث المباشر (Live Autocomplete)**:
   - قائمة منسدلة فورية تظهر أثناء الكتابة تعرض صور المنتجات وأسعارها.
6. **سلة التسوق والسلة الدائمة (Persistent Cart)**:
   - درج سلة جانبي سريع (Drawer) وصفحة سلة كاملة.
   - حفظ السلة في قاعدة البيانات للمستخدم المسجل وتزامنها بين الأجهزة.
   - شريط تقدم الحصول على الشحن المجاني التفاعلي.
   - كود الخصم (Coupon) مع تطبيق مباشر.
7. **إتمام الطلب (Checkout)**:
   - اشتراط تسجيل الدخول لحفظ الطلب ومتابعته.
   - بيانات الشحن والتوصيل مع الحفظ التلقائي في ملف العميل.
   - خيارات الدفع: الدفع عند الاستلام (COD) والدفع بالبطاقة الإلكترونية التجريبية.
   - توليد رقم طلب رسمي فريد مثل (`SUKI-88219`).
8. **تتبع الطلبات والفواتير**:
   - شريط مسار التتبع البصري (Order Stepper Timeline): تم الاستلام -> قيد التجهيز -> قيد الشحن -> تم التسليم.
   - سجل التحديثات مع التوقيت والملاحظات.
   - زر طباعة فاتورة احترافية منسقة للطباعة (`@media print`).
9. **الأمان وتسجيل الدخول**:
   - تشفير كلمات المرور باستخدام خوارزمية `Bcrypt`.
   - توثيق آمن عبر `JSON Web Tokens (JWT)`.
   - فرادة البريد الإلكتروني ورقم الجوال ومنع التكرار.
   - **حماية من الهجمات**: قفل مؤقت (15 دقيقة افتراضياً، قابل للتعديل من `.env`) بعد 5 محاولات فاشلة.
   - شاشة التحقق التجريبي من رمز OTP تمهيداً لربط بوابات الرسائل القصيرة.
10. **مركز الدعم والصفحات الثابتة**:
    - نموذج تواصل معنا مع حفظ الرسائل مباشرة في لوحة التحكم.
    - وسائل الاتصال المباشرة ومواعيد العمل والأسئلة الشائعة (FAQ).
    - صفحات: من نحن، سياسة الخصوصية، والشروط والأحكام.

---

### 🛡️ ثانياً: لوحة تحكم الإدارة والموظفين (Admin Dashboard)
1. **الوصول والأمان**:
   - مسار مخصص `/admin` مفصول تماماً ومحمي من خادم Express والواجهة.
   - منع دخول العملاء العاديين نهائياً (403 Forbidden).
   - قائمة جانبية ذكية تظهر **فقط** الأقسام المصرح بها لكل موظف.
2. **صلاحيات المدير العام (Super Admin)**:
   - التحكم الكامل في كل الحسابات.
   - قفل أو فتح أي حساب بنقرة زر.
   - تغيير البريد الإلكتروني أو كلمة المرور لأي حساب.
   - استعراض سجل ونشاط مشتريات أي عميل.
   - إدارة حسابات الموظفين ومنح أو سحب الصلاحيات منهم.
3. **أقسام لوحة التحكم**:
   - **الداشبورد**: بطاقات مؤشرات الأداء، رسم بياني تفاعلي للمبيعات اليومية، أكثر المنتجات مبيعاً، وتوزيع حالات الطلبات.
   - **إدارة المنتجات**: إضافة، تعديل، حذف، رفع صور، خيارات ديناميكية، وتحديد وحدات البيع.
   - **إدارة الأقسام**: إضافة وتعديل وحذف وترتيب الأقسام.
   - **إدارة الطلبات**: فلترة بالحالة، تغيير الحالة مع ملاحظة وإشعار العميل، وتفاصيل الفاتورة.
   - **إدارة العملاء**: جدول شامل، بحث سريع، قفل/فتح الحساب، وتعديل البيانات.
   - **إدارة الموظفين**: إضافة موظف مع مصفوفة الصلاحيات بالـ Checkboxes.
   - **إدارة الكوبونات**: خصم نسبة أو مبلغ ثابت، حدود دنيا، حد أقصى وتاريخ انتهاء.
   - **إدارة البانرات**: إضافة وتعديل وحذف بانرات السلايدر وروابطها.
   - **إدارة رسائل الدعم**: صندوق الوارد للرسائل، الرد عليها، وتحديث حالة المعالجة.

## 🔒 الأمان والحماية المضمنة
- قفل تسجيل الدخول مؤقتاً (15 دقيقة افتراضياً) بعد 5 محاولات فاشلة، ورسالة خطأ موحدة لا تكشف وجود الحساب.
- كود التحقق بالبريد (OTP): صالح 10 دقائق، 5 محاولات فقط، ولا يُرسل أبداً في رد الخادم.
- تسجيل الدخول بجوجل يتطلب توكن حقيقياً من جوجل، وحسابات الإدارة والموظفين تدخل بكلمة المرور فقط.
- كوكي الجلسة HttpOnly + SameSite، وإلغاء كل الجلسات القديمة عند تغيير كلمة المرور أو "الخروج من كل الأجهزة".
- Helmet (رؤوس أمان)، CORS مقيد بموقعك، حدود لعدد الطلبات على الدخول وإنشاء الطلبات.
- منع رفع ملفات قابلة للتنفيذ (svg / html ...)، وتقديم الملفات المرفوعة بوضع معزول.
- إخفاء سعر التكلفة والعمولة وبيانات التاجر/المستثمر عن العملاء والزوار.
- عمليات كتابة ذرية (Atomic Writes) لمنع تلف البيانات عند انقطاع الكهرباء أو إعادة التشغيل.

### إعدادات مهمة في `.env` قبل النشر
- `NODE_ENV=production` و `JWT_SECRET` (32 حرفاً على الأقل، وإلا لن يعمل الخادم في الإنتاج).
- `ALLOWED_ORIGINS` و `TRUST_PROXY` (عند العمل خلف Cloudflare أو Proxy).
- `RESEND_API_KEY` و `RESEND_FROM` على دومين موثّق في Resend حتى تصل أكواد التسجيل للعملاء.
- `OTP_DEBUG_ECHO=true` للتجربة المحلية فقط (يُتجاهل في الإنتاج).
- راجع `.env.example` لكل الإعدادات.

> ⚠️ لا تشغّل نسختين من الخادم على نفس مجلد `database/data` في نفس الوقت (يسبب تكرار الإشعارات وتعارض الكتابة).
