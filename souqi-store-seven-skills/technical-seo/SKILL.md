# Technical SEO & Performance
- Inspect rendering strategy (server-rendered, static or client-rendered), URL patterns, robots.txt, sitemap, metadata, canonicals, internal links and indexability before recommending changes.
- Review unique titles/descriptions, stable URLs, canonical and pagination/filter behavior, product/category content, breadcrumbs, image alt text and internal linking.
- Validate Product/Offer/Breadcrumb structured data using only real product names, prices, currency, availability and other truthful fields. Never fabricate reviews, ratings or shipping promises.
- Check how product/category create, update, delete and stock changes affect metadata and sitemap. Prefer automated generation from the store's source of truth.
- Handle deleted products and redirects/404 behavior deliberately.
- Measure performance before optimizing. Review images, caching, compression, JS/CSS payloads, render-blocking resources, server response and Core Web Vitals where measurable.
- Report measured values and test conditions; never invent scores.
- Obtain approval before changing URL structures, indexing directives, canonicals or production SEO settings.
