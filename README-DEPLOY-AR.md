# سوقي ستور — نسخة عرض مؤقتة

هذه نسخة منفصلة للعرض فقط، وليست نسخة تشغيل تجاري.

## النشر المجاني على Render
1. أنشئ مستودع GitHub جديدًا (يفضّل Private).
2. فك ضغط ملف ZIP وارفع **محتويات المجلد** إلى جذر المستودع.
3. افتح https://dashboard.render.com/ ثم New → Blueprint.
4. اختر مستودع GitHub الذي رفعته، ثم طبّق `render.yaml`.
5. انتظر انتهاء النشر، وسيظهر رابط عام بصيغة `*.onrender.com`.

## إعدادات النسخة
- Node.js 22.16.0 (مطلوب لدعم `node:sqlite`).
- SQLite مؤقتة تُنشأ تلقائيًا ببيانات عرض أولية.
- وضع القراءة فقط: يمنع تسجيل الدخول ولوحة الإدارة والطلبات والكتابة والرفع.
- لا توجد ملفات `.env` أو نسخ احتياطية أو قواعد بيانات محلية ضمن الحزمة.
- Render Free يوقف الخدمة بعد 15 دقيقة من عدم النشاط، وقد يستغرق فتحها أول مرة بعد النوم نحو دقيقة.

## تنبيه عن البيانات
ملف ZIP الأصلي لم يتضمن ملف قاعدة SQLite النشط؛ ونسخ SQLite الاحتياطية الموجودة كانت تحتوي سجلات مستخدمين ونشاط ولا تحتوي منتجات. لذلك لم تُضمّن أي نسخة احتياطية. سيُنشئ التطبيق قاعدة عرض جديدة ببيانات seed الموجودة في المشروع.
